# Search, generative and answer discovery
One canonical public entity: FreshPick Sri Lanka, food discovery and editorial platform. No checkout/stock claims. The route /llms.txt replaces the obsolete static grocery file. Search/answer crawlers can access public pages; private endpoints remain restricted. This is optional guidance, not an AI ranking signal. Department answers are visible HTML, not hidden schema text. Colombo guide uses existing source-linked editorial references, not fake businesses or programmatically generated thin location pages. Other towns should receive unique verified content before indexing. Collection and breadcrumb structured data describe visible content. MenuItem and Product markup intentionally do not assert price, offers, stock, ratings or rich-result eligibility; Product without offers/reviews may not qualify for Google rich results. Sitemap timestamps come from actual database updates, not today's date.

## Release checks
Verify canonical hostname redirects, HTML metadata, robots, sitemap, JSON-LD, real source links and server rendering after deployment. Submit sitemap to verified Google Search Console and Bing Webmaster Tools. Check URL indexing and Core Web Vitals, query impressions/clicks, conversions, and periodic AI citation samples. No access to verified Search Console metrics established. Do not promise rankings or 100% visibility. Do not add invented reviews, misleading availability, duplicate pages, paid backlinks or mass generated text.
