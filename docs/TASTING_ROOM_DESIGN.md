# FreshPick — Tasting Room finish
A hospitality-inspired refinement to the approved curated discovery layout. The signature is a dark cacao gifting feature with inset rounded photography and warm bronze CTA, rather than a new navigation or grocery hero. Keep the actual original green/amber SVG wordmark. Use limestone #F8F5EE as paper, #FFFDF8 as surface, tea-green #244539 for action, #202E28 for text, #535F56 for muted text, #49362B cacao for gift feature/footer, #C9A36B bronze as an accent with dark ink, and #E9EDE5 for soft sage. Instrument Serif is retained as the locally hosted display face; system UI sans for searchable and readable controls. Rounded photographs 16px, larger surfaces 24px, form fields 12px, pill CTAs. Keep editorial rules, avoid wrapping every section in a card, use existing licensed editorial images and no fabricated venue photographs. Changes are scoped to public/auth experiences; admin is excluded. No dependencies, migrations, or booking changes.
