# Search authority and quality gate
This release extends PR #185. It adds source-linked editorial policy, public RSS for up to 50 published dish/tradition/guide entries (not a complete inventory), consistent Article markup and real visible modification dates, food names in Sinhala/Tamil where already available, Atlas collection schema, and noindex for historical checkout refund support. Do not invent dates for static field notes. Keep old support accessible by direct URL. RSS is a syndication format, not a guaranteed ranking signal.
The browser audit validates actual rendered HTML (not a static code score): canonical, unique page title, description, one H1, indexable state, sitemap membership, parseable JSON-LD, actual article dates and source, noindex filters, valid feed, and llms policy link. Runs in the existing isolated visual workflow, writes seo-audit.json. No paid service or migration. Set NEXT_PUBLIC_SITE_URL to the actual canonical origin if running against a deployed site. Google uses ordinary SEO for AI Search; llms.txt is optional and is not used by Google Search. Do not interpret passing checks as 100% visibility or Lighthouse results.
After production rollout, run URL Inspection and sitemap submission in Google Search Console and Bing Webmaster Tools. Measure clicks, impressions, queries, business registration and referral conversions, Core Web Vitals, and AI citations. Maintain a human-reviewed source register. Expand only substantive original content, not city/keyword doorway pages. Prioritize comparisons, food culture, original price research with dated methodology, and real owner pages. No automated scraping or claims of ranking guarantees.
