## Repeatable capture

The PR visual-review workflow builds the current branch against a dedicated ephemeral PostgreSQL database, with expressly fictional test records that never reach production. The workflow uploads actual browser PNGs under the artifact name `freshpick-390-and-1440-review` for inspection. The fixture has no uploaded item photograph; it exercises the honest no-image fallback, not a real maker photo crop. The script also accepts existing approved maker/item/story paths via VISUAL_MAKER_PATH, VISUAL_ITEM_PATH, VISUAL_STORY_PATH, and a running historical URL via HISTORICAL_BASE_URL. VISUAL_LOGIN and VISUAL_PASSWORD must be credentials for a non-sensitive test maker, never an actual personal account. Run locally with playwright installed and Chromium available. Historical captures require an independently running historical server. The workflow has not been executed or reviewed at authoring time.
