# Food & Culture CMS
Admin > Publishing > Food & Culture CMS (/admin/discovery-content). Create and edit dish/Atlas entries, traditions and dated events; drafts private, publish/unpublish with source confirmation, immutable slug/type, optimistic version check, editor ID. Enter event dates in Sri Lanka local time; API stores UTC timestamps and public dates display Asia/Colombo. Events need start, end, location and source when published. Expired events disappear from upcoming list, their detail pages remain as historical records unless unpublished. Link traditions/events to existing dish slugs. No booking, ticketing, image upload or automated event import. Plain text editorial content; URLs validated as HTTPS. Source confirmation is an editorial responsibility. The public Atlas now reads the database, not the static starter array. Drafts do not appear in sitemap or public pages.
Deployment: before releasing this PR, back up the target database and run `npx prisma migrate deploy` using the verified direct/session database connection. Migrations 20261127224500_discovery_content_cms and 20261127225000_food_traditions_seed add the restricted table and seed the existing four dish entries plus two evergreen traditions. No real upcoming event seeded. Do not manually apply then run migrate deploy again without reconciling migration history. Preview database also needs migrations before public Atlas pages work. CI uses isolated PostgreSQL and exercises admin authorization, draft/publish/unpublish and stale edits using fictional fixtures. No production data was changed.
