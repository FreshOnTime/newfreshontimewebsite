# FreshPick Live
Public /live, homepage shelf, Explore category and Experiences link. Admin > Business > Live vendors. Business Studio > Live. Existing approved/published business profiles apply for one mobile vendor type; approval requires manual identity and location-consent review. Vendors check in with a public serving address, area, optional GPS pin and 1–12 hour duration. GPS is explicitly triggered, not tracked in background. A stop is vendor-reported, not independent proof of availability. Only approved, active, published suppliers with non-banned supplier accounts and unexpired sessions are public. Public API returns an allowlist, no private review notes or IDs. Stops are replaced rather than stored as route history; stop and admin review clear location immediately. Expired stops are excluded from public queries; last values remain restricted until overwritten/cleared. Public page refreshes every 30 seconds when visible, hides locations if refresh fails; homepage is a server snapshot. External map search/pin links avoid map-tile API fees. No embedded map, continuous tracking, route history, scheduled stops, notifications or bookings in MVP. Future scheduled cleanup of expired private coordinates and vendor schedules, opt-in follows, maps/nearby search after pilot. No real vendor data seeded. Start with 5–10 consenting vendors.
